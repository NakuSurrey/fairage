# Artifacts

Generated outputs from training and export. Most files here are gitignored — they are too large or change on every run.

## Folder layout

```
artifacts/
├── checkpoints/                  # gitignored — torch .pt files saved during training
│   ├── age_best.pt               # best epoch by validation MAE
│   └── pad_best.pt               # best epoch for PAD detector
│
├── exports/                      # gitignored — onnx + tflite for deployment
│   ├── age_model.onnx
│   ├── age_model.tflite          # quantised int8, the production model
│   └── pad_model.tflite
│
├── bias_report.json              # tracked — per-group MAE table from Phase 5 audit
├── benchmark_results.json        # tracked — CPU latency numbers from Phase 7
└── README.md                     # this file
```

## What is tracked vs ignored

- **Tracked in git**: small JSON reports — `bias_report.json`, `benchmark_results.json`. These are the proof-of-work for the README and live on GitHub.
- **Ignored**: every model file. Too big for git, regenerated by the training pipeline.

## How each file is produced

| File | Created by | Phase |
|------|------------|-------|
| `checkpoints/age_best.pt` | `src/training/train_age.py` on Surrey HPC | 3, 4 |
| `checkpoints/pad_best.pt` | `src/training/train_pad.py` on Surrey HPC | 6 |
| `exports/age_model.onnx` | `src/deploy/export_onnx.py` | 7 |
| `exports/age_model.tflite` | `src/deploy/onnx_to_tflite.py` | 7 |
| `bias_report.json` | `src/audit/bias_audit.py` | 5 |
| `benchmark_results.json` | `src/deploy/benchmark.py` | 7 |

## Transferring artifacts between machines

Training happens on Surrey HPC. The API runs on Hetzner. Checkpoints move via:

```bash
# from laptop, after training finishes — pull from HPC
scp $HPC_USER@$HPC_LOGIN_NODE:~/fairage/artifacts/checkpoints/age_best.pt artifacts/checkpoints/

# then push to Hetzner for serving
scp artifacts/exports/age_model.tflite $HETZNER_USER@$HETZNER_HOST:/srv/fairage/
```
